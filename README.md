---

## Overview

A Streamlit-based diagnostic assistant that takes patient biomarkers (age, blood pressure, cholesterol, glucose, etc.) and runs them through a trained classification model to estimate disease risk probability. Designed to support — not replace — clinical judgment.

**Topics:** `classification` · `data-science` · `deep-learning` · `disease-prediction` · `health-ai` · `machine-learning` · `medical-diagnosis` · `neural-networks` · `streamlit` · `cnn-on-xray-mri`

---

## Features

- Interactive patient parameter input with range validation
- Risk probability output with confidence interval display
- Feature contribution breakdown (SHAP / importance scores)
- Model comparison panel (Logistic Regression, RF, SVM, XGBoost)
- Clean, clinically neutral UI with accessible colour palette

---

## Tech Stack

Stack: Jupyter Notebook, Python. Libraries: Streamlit, scikit-learn, SHAP, pandas, Plotly.

**Key dependencies detected:** `scikit-learn` · `numpy` · `pandas` · `matplotlib` · `seaborn` · `scipy` · `xgboost` · `lightgbm` · `catboost` · `tensorflow`
